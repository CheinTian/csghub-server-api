# POST /api/v1/storage/{bucket}/{key}

**Resource:** [StorageGateway](../resources/StorageGateway.md)
**Upload object via presigned POST policy**
**Operation ID:** `post--api-v1-storage-{bucket}-{key}`

Reverse proxies a presigned POST policy upload (multipart form) to OSS. The object key and signature are carried in the form body and verified by OSS, so no ApiKey authentication is applied to this endpoint (any Authorization header is stripped before forwarding). The presigned POST policy generated by this product does not set success_action_status, so a successful upload always returns 204 No Content with an empty body.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `bucket` | path | string | Yes | Bucket name |
| `key` | path | string | Yes | Object key |

## Responses

| Status | Description |
|--------|-------------|
| 204 | No Content (empty body) |
| 400 | Bad request |
| 500 | Internal server error |
