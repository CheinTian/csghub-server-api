# GET /admin/common/organizations/mine

**Resource:** [Admin Common](../resources/Admin-Common.md)
**List my organizations for administrator navigation**
**Operation ID:** `get--admin-common-organizations-mine`

Requires active administrator membership in both services and the enabled hierarchy feature. Existing organization membership filters remain in effect.

## Responses

| Status | Description |
|--------|-------------|
| 200 | OK |
| 401 | Unauthorized |
| 403 | Forbidden |
| 500 | Internal Server Error |
